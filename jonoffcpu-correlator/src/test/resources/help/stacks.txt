Usage: java -jar jonoffcpu-correlator.jar stacks [-hV] [--canonical-names] [--list-presets]
                                                 [--collapse-leaf-label=LABEL]
                                                 [--collapsed-input=FILE] [--output=FILE]
                                                 [--package-names=MODE] [--profile=FILE]
                                                 [--reason=REASONS] [--reason-frame=MODE]
                                                 [--root-at-unmatched=MODE] [--stack=KINDS]
                                                 [--summary=FILE] [--thread-frame=MODE]
                                                 [--time=PART] [--weights=WEIGHTS]
                                                 [--collapse-leaf=REGEX]...
                                                 [--collapse-leaf-from=FILE]...
                                                 [--exclude=REGEX]... [--exclude-from=FILE]...
                                                 [--hide=REGEX]... [--hide-from=FILE]...
                                                 [--include=REGEX]... [--include-from=FILE]...
                                                 [--leaf-at=REGEX]... [--leaf-at-from=FILE]...
                                                 [--root-at=REGEX]... [--root-at-from=FILE]...
                                                 [--trim-root=REGEX]... [--trim-root-from=FILE]...
Renders one collapsed slice of a stack profile: by switch-out reason, stack kinds, weights and time
part, keeping or dropping whole intervals by their frames and transforming the frames of the ones
it keeps.
With --collapsed-input, filters and transforms any collapsed file instead, such as a CPU view the
converter wrote.
      --profile=FILE         The stack profile, such as jonoffcpu-offcpu-profile.pb. Required
                               unless --collapsed-input is given.
      --reason=REASONS       all, or a comma-separated list of blocked, runnable, preempted and
                               unspecified. Default: all.
      --stack=KINDS          Which stacks a line is made of: java, kernel, user, java+kernel or
                               java+user+kernel. Default: java.
      --weights=WEIGHTS      observed durations, or the estimated inverse-probability population
                               when the profile's estimate is available. Default: observed.
      --time=PART            Which part of each interval's time is weighed: total, sleeping,
                               runqueue, or split (the whole time, each line ending in its part's
                               frame). Default: total.
      --package-names=MODE   How a Java frame's package is shown: full, abbreviate (initials) or
                               drop. Default: full.
      --collapsed-input=FILE Read any collapsed file instead of --profile. Weights keep the file's
                               unit; the converter's Java frames lose their _[j]-style markers and
                               '/' in class names.
      --output=FILE          The collapsed file to write; must not exist. Required.
      --reason-frame=MODE    Whether each line starts with its [offcpu: <reason>] frame: auto (when
                               the slice mixes reasons), always or never. Default: auto.
      --summary=FILE         Also write a JSON summary of the slice: its totals, patterns,
                               transforms and what the filters removed.
      --list-presets         Print the bundled pattern presets and exit.
      --include=REGEX        Keep only intervals with a frame matching the pattern; repeatable, any
                               matches.
      --exclude=REGEX        Drop every interval with a frame matching the pattern; repeatable, and
                               an exclusion wins.
      --include-from=FILE    Read --include patterns from a file, one per line, or a bundled preset:
                               NAME; repeatable.
      --exclude-from=FILE    Read --exclude patterns from a file, one per line, or a bundled preset:
                               NAME such as preset:jvm-idle; repeatable.
      --canonical-names      Remove generated-class addresses ($Lambda.0x..., LambdaForm$MH/0x...),
                               so two runs' stacks compare.
      --hide=REGEX           Remove every frame that matches, anywhere in the stack; a stack of
                               nothing else keeps its leaf. Repeatable.
      --hide-from=FILE       Read --hide patterns from a file or preset:NAME; repeatable.
      --trim-root=REGEX      Remove the longest root-side run of matching frames, such as thread
                               and event-loop entry points; deeper frames stay even if they match.
                               Repeatable.
      --trim-root-from=FILE  Read --trim-root patterns from a file or preset:NAME, such as preset:
                               jvm-infra; repeatable.
      --root-at=REGEX        Start the stack at the root-most matching frame, such as your
                               application's first frame. Repeatable.
      --root-at-from=FILE    Read --root-at patterns from a file or preset:NAME; repeatable.
      --root-at-unmatched=MODE
                             A stack without a --root-at match: bucket (becomes the single frame
                               [no application frame]) or keep (unchanged). Default: bucket.
      --leaf-at=REGEX        Cut the callees of the leaf-most matching frame, keeping the match.
                               Repeatable.
      --leaf-at-from=FILE    Read --leaf-at patterns from a file or preset:NAME; repeatable.
      --collapse-leaf=REGEX  Replace the longest leaf-side run of matching frames, the wait
                               machinery, by its root-most frame, such as ReentrantLock.lock.
                               Repeatable.
      --collapse-leaf-from=FILE
                             Read --collapse-leaf patterns from a file or preset:NAME, such as
                               preset:jvm-wait-machinery; repeatable.
      --collapse-leaf-label=LABEL
                             What replaces a collapsed run: frame (its root-most frame) or category
                               ([monitor], [lock], [park], [wait], [sleep], [native] or [kernel]).
                               Default: frame.
      --thread-frame=MODE    Start each line with the thread's name, or its pool (digit runs
                               replaced by #: pulsar-io-3-25 is pulsar-io-#-#); needs the profile's
                               thread dimension. none, name or pool. Default: none.
  -h, --help                 Show this help message and exit.
  -V, --version              Print version information and exit.

Per kept entry, in this order: --canonical-names, --hide, --trim-root, --root-at, --leaf-at,
--collapse-leaf, then --package-names and --thread-frame as display. Filters see the untransformed
stacks, and lines that transform alike merge, so totals never change. Every -from option also takes
preset:NAME; --list-presets prints them.
