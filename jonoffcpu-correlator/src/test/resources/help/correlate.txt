Usage: java -jar jonoffcpu-correlator.jar correlate [-hV] [--audit=LEVEL]
       [--collapsed-reason-frame=MODE] [--estimate-population=true|false] [--format=FORMAT]
       [--from=TIME] [--from-ns=N] [--jfr=FILE] [--max-accounted-loss=F] [--max-handler-delay-ns=N]
       [--max-profile-entries=N] [--max-retained-bytes=N] [--max-rows=N] [--on-limit=POLICY]
       [--output=DIR] [--partial=true|false] [--partial-jfr=true|false] [--profile-group-by=LIST]
       [--profile-output=true|false] [--source=FILE] [--summary-output=true|false] [--thinning=Q]
       [--thinning-seed=N] [--to=TIME] [--to-ns=N] [--app=REGEX]... [--app-from=FILE]...
       [--hide=REGEX]... [--hide-from=FILE]... [--idle=REGEX]... [--idle-from=FILE]...
Correlates a capture with its JFR into a new output directory (the default command).
      --source=FILE          The finalized capture stream the agent wrote (jonoffcpu-capture.pb).
                               Required.
      --jfr=FILE             The combined JFR recorded with the capture. Required.
      --output=DIR           The output directory, which must not exist yet. Required.
      --from=TIME            Select samples from this JFR event time: an ISO-8601 timestamp, epoch
                               milliseconds, a duration, or an offset from the recording start such
                               as 30s or 2m.
      --to=TIME              Select samples up to this JFR event time.
      --partial-jfr=true|false
                             Accept a JFR that another tool has cut; source rows without a sample
                               in it are expected omissions, not loss. Default: false.
      --from-ns=N            Clip matched intervals to start at this source monotonic time.
      --to-ns=N              Clip matched intervals to end at this source monotonic time.
      --max-handler-delay-ns=N
                             Reject matches whose Java stack was captured more than this long after
                               the interval ended.
      --max-rows=N           Most source rows admitted. Default: 100000000.
      --max-retained-bytes=N Retained-bytes budget. Default: sixty percent of the heap, never below
                               256 MiB.
      --format=FORMAT        Which derived outputs to write: collapsed, the only choice for a
                               complete analysis; with --partial true, diagnostics or collapsed.
                               Default: collapsed, or diagnostics with --partial true.
      --estimate-population=true|false
                             Report the inverse-probability population estimate. Requires the
                               complete, unselected JFR and an unthinned source. Default: false.
      --max-accounted-loss=F The largest fraction of selected intervals the collector may have
                               dropped under counted sequence contention for the population
                               estimate to stay available, scaled up by the loss (0 <= F < 1).
                               Default: 0.01.
      --audit=LEVEL          Per-row audit output: full, matches or none. Default: matches, which
                               writes jonoffcpu-matches.jsonl but not jonoffcpu-classified-records.
                               jsonl.
      --thinning=Q           Keep each recorded interval with probability Q (0 < Q <= 1) and
                               reweight by 1/Q, deterministically in the cookie. Default: chosen
                               automatically, and 1 whenever the input fits.
      --thinning-seed=N      Changes the deterministic draw --thinning uses. Default: 0.
      --on-limit=POLICY      What to do when the retained-bytes budget is reached: degrade
                               (coarsen, drop audit, thin, narrow, reporting each step), fail, or
                               truncate (narrow the window directly). Default: degrade.
      --partial=true|false   Inspect an interrupted capture: writes INCOMPLETE-jonoffcpu-* files
                               and jonoffcpu-partial.json, exits with status 2, and never writes
                               jonoffcpu-complete.json. Default: false.
      --collapsed-reason-frame=MODE
                             Whether each line of jonoffcpu-offcpu-stacks.collapsed starts with its
                               [offcpu: <reason>] frame: auto (when the capture mixes reasons),
                               always or never. Default: auto.
      --profile-output=true|false
                             Whether to write jonoffcpu-offcpu-profile.pb. Default: true.
      --profile-group-by=LIST
                             The profile's optional dimensions besides the Java stack and the
                               reason: any of kernel, user, thread, or none. Default: kernel,user,
                               thread.
      --summary-output=true|false
                             Whether to write the analysis digest, jonoffcpu-summary.md and
                               jonoffcpu-summary.json, from the profile and the report. A failure
                               to write it is reported in the report and never fails the
                               correlation. Default: true.
      --idle=REGEX           For the digest: an interval with a frame matching this is idle, a wait
                               for work, and the digest's tables and stacks leave it out. The other
                               outputs keep every interval. Repeatable.
      --idle-from=FILE       Read --idle patterns from a file or preset:NAME; repeatable. Default,
                               when no idle pattern is given: preset:jvm-idle.
      --app=REGEX            For the digest: a frame of your application. Its tables then start
                               each stack at the first one and name the last one before each wait,
                               and count busy time without one apart, by pool. Repeatable.
      --app-from=FILE        Read --app patterns from a file or preset:NAME; repeatable.
      --hide=REGEX           For the digest with --app: remove matching frames, such as executors
                               that only run a task, before each stack is rooted at the
                               application. Repeatable.
      --hide-from=FILE       Read --hide patterns from a file or preset:NAME; repeatable. Default,
                               with --app and no hide pattern: preset:jvm-dispatch.
      --max-profile-entries=N
                             Entry limit for the profile; past it the thread, then the user and the
                               kernel stack are dropped from the grouping. Default: 2000000.
  -h, --help                 Show this help message and exit.
  -V, --version              Print version information and exit.
