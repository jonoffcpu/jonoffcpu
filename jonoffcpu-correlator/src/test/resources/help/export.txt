Usage: java -jar jonoffcpu-correlator.jar export [-hV] [--format=FORMAT] [--numbers=FORM]
                                                 [--output=FILE] [--profile=FILE]
                                                 [--run-label=TEXT] [--run-metadata=FILE]
Writes one row per stack-profile entry, stacks expanded, for tools such as DuckDB.
JSON Lines rows carry the stacks as arrays too, counters as numbers, and every row names its run
and whether its estimated columns may be used.
      --profile=FILE        The stack profile to export. Required.
      --format=FORMAT       csv or jsonl. Default: csv.
      --output=FILE         The file to write. Required.
      --run-label=TEXT      The run column of every row, for loading several runs into one table.
                              Default: the profile's label, else its first source's session id.
      --run-metadata=FILE   Also write one JSON object describing the profile: its run, sources,
                              sampling, dimensions, estimate validity and totals.
      --numbers=FORM        How JSON Lines counters are written: number (a string only past 2^53-1)
                              or string, as before 0.5.0. Default: number.
  -h, --help                Show this help message and exit.
  -V, --version             Print version information and exit.
